# 🌟 Vision

Traditional voice assistants answer questions.

N.O.V.A. performs work.

Instead of simply responding to prompts, N.O.V.A. understands context, plans actions, controls desktop applications, automates workflows, remembers conversations, and executes complex multi-step tasks through natural language.

The long-term vision is to build an intelligent desktop operating companion capable of acting as a personal productivity assistant while remaining privacy-first through local AI inference.

# 🏗 System Architecture

<p align="center">

<img src="docs/images/architecture.png" width="100%">

</p>

N.O.V.A. follows a layered modular architecture.

```
User
    ↓
Voice/Text Input
    ↓
Speech Processing
    ↓
Intent Parsing
    ↓
Context Resolution
    ↓
Execution Orchestrator
    ↓
Planner / Agent
    ↓
Capability Layer
    ↓
Windows APIs
    ↓
Execution Context
    ↓
Memory Update
    ↓
Speech Response
```

The system separates reasoning from execution, making every module independently extensible.

# 🧩 Core Components

| Component | Responsibility |
|-----------|---------------|
| Voice Engine | Speech recognition & synthesis |
| Intent Parser | Natural language understanding |
| Context Resolver | Context-aware command resolution |
